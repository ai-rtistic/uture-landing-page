# 유쳐(Uture) 랜딩페이지 리뉴얼 — 설계 문서

**날짜:** 2026-06-21
**목표:** twelvelabs.io/ko 의 디자인·레이아웃·인터랙션을 픽셀·모션 수준으로 재현해, 유쳐(AI·AX 에이전시)의 콘텐츠로 채운 새 랜딩페이지를 `web/`에 구축한다. `legacy/`(구 소스)는 수정하지 않는다.

## 1. 기술 스택

- **Vite + React 18 + TypeScript** — 프로덕션 빌드/배포 가능 (마켓플레이스급)
- **Tailwind CSS** + `:root` 디자인 토큰 CSS 변수
- **GSAP + ScrollTrigger** — 핀 고정, 스크럽, 텍스트 컬러 리빌, 카운트업
- **Lenis** — 스무스 스크롤
- **폰트** — Pretendard(한글, 가변), Geist(라틴/숫자). 셀프호스팅 또는 CDN.
- **에셋** — `legacy/assets/`의 로고·고객사 로고 PNG를 `web/public/assets/`로 복사(원본 미수정).

## 2. 디자인 토큰 (레퍼런스 1:1)

```
--bg:        #f4f3f3   /* 페이지 배경 (오프화이트) */
--surface:   #ffffff   /* 카드 */
--surface-2: #ececec   /* 보조 배경 */
--text:      #1d1c1b   /* 본문/제목 (웜블랙) */
--text-2:    #3e3e3c   /* 보조 텍스트 */
--muted:     #8e8d8d   /* 캡션/비활성 */
--border:    #d3d1cf   /* 헤어라인 디바이더 */
--border-2:  #dbdad8

/* 단어별 컬러 하이라이트 팔레트 */
--c-pink:   #ffb0cd
--c-blue:   #0099ff
--c-green:  #20df9e
--c-orange: #faba17
--c-purple: #a7abff
--c-neon:   #60e21c   /* 글로우 보더 */
```

- 컨테이너 max-width **1200px**, 좌우 패딩 40px(데스크톱).
- 히어로 헤딩 56–64px / line-height ~1.0 / letter-spacing -0.02em.
- 섹션 헤딩 40–48px, 본문 16–18px / line-height 1.5.
- 다크 pill 버튼: bg `#1d1c1b`, 흰 텍스트, radius 14px, padding 10–14px 18–20px, 화살표(↗) 포함.
- 아웃라인 버튼/배지: 1px `#d3d1cf`, radius 14–20px, 흰 배경.
- 섹션 세로 패딩 넉넉히(120–200px), 헤어라인으로 섹션 구분.

## 3. 모션 시그니처 (재현 대상)

1. **핀 고정 + 블러 크로스페이드** — 한 화면을 핀으로 고정하고 스크롤에 따라 01·02·03 문장이 blur(8→0px)+opacity로 교차 전환.
2. **단어별 컬러 리빌** — 인용문이 스크롤 진행도에 따라 단어 단위로 회색→컬러(팔레트 순환)로 채워짐.
3. **흐르는 그라디언트 파이프라인** — 노드(라이브러리→모델→임베딩→API) 사이를 베지어 곡선 + 흐르는 컬러 도트/리본으로 연결(SVG + GSAP).
4. **네온 글로우 보더 카드** — 둥근 카드 가장자리에 그린 그라디언트 글로우가 은은히 움직임.
5. **떠다니는 3D 그라디언트 캡슐** — 최종 CTA 배경에 블러된 그라디언트 둥근 막대들이 회전·부유.
6. 보조: 스크롤 리빌(아래에서 페이드업), 숫자 카운트업, 마퀴(로고·칩), nav 스크롤 축소.

## 5. 컴포넌트 구조 (`web/src/`)

```
main.tsx, App.tsx
lib/        useLenis.ts, gsap.ts(등록), useReveal.ts, useCountUp.ts, useWordReveal.ts, usePinnedBlur.ts
data/       content.ts (모든 유쳐 카피·통계·케이스·푸터를 타입 지정 상수로)
components/  Nav, Hero, PinnedNarrative, LogoMarquee, Testimonial,
            FeatureCards, FdePipeline, IndustryCards, ServiceTabs,
            CaseQuote, GlowCTA, ProcessColumns, StatsStrip, Philosophy,
            FinalCTA, Footer
ui/         Button, Pill, Container, SectionHeader, WordReveal
styles/     globals.css (토큰, base, 폰트)
```

- `content.ts`를 단일 진실 소스로 두어 카피 수정이 쉽도록 한다.
- 각 섹션 컴포넌트는 자기 모션 훅만 의존, 독립 테스트/이해 가능하게 분리.

## 6. 접근성·성능·반응형

- prefers-reduced-motion 존중(모션 축소 시 즉시 표시).
- 이미지 lazy-load, 폰트 preconnect, GSAP/ScrollTrigger 동적 import.
- 브레이크포인트: 모바일(≤640), 태블릿(≤1024), 데스크톱. 모바일은 핀/파이프라인을 단순 페이드/세로 스택으로 폴백.

## 7. 비범위 (YAGNI)

- 다국어(영/일) 스위처 — KO 단일(언어 토글 UI만 자리, 동작 생략).
- 실제 백엔드/폼 전송 — CTA는 mailto 유지.
- twelvelabs의 실제 3D/캔버스 에셋 원본 재현은 불가 → SVG/CSS 그라디언트로 고충실 근사.
