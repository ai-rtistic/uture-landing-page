# 유쳐(Uture) 브랜드 컨셉 & Hero 배경 영상 설계

작성일: 2026-06-28
상태: 컨셉 확정 (서비스 3축 + Hero 모션 방향)

---

## 1. 기업 정의

**유쳐 = 현장에 들어가는 AX 파트너.**

기업에 직접 들어가 *구성원 한 명 한 명*의 일하는 방식을 AI로 바꾸고, 그것이 조직에
정착될 때까지 함께한다. 강의만 하고 떠나지 않는다 — 교육 그 다음을 책임진다.

- 한 줄: "AI를 *아는* 조직에서 AI로 *일하는* 조직으로."
- 차별점: 범용 강의가 아니라, 각 구성원의 **실제 업무** 위에서 결과물을 함께 만들고,
  필요하면 사내 환경·보안에 맞는 도구까지 만들어 정착시킨다.

## 2. 3개 핵심 서비스 축

교육 → 실전 코칭 → 자산화로 이어지는 하나의 흐름. 이 3축이 곧 "아는 조직 → 일하는 조직"의 경로다.

### ① 구성원 교육
직무·숙련도별 맞춤 트랙으로 조직의 AI 기준선을 끌어올린다.

- 비개발 실무자 대상 핸즈온 워크샵
- 전사 생성형 AI 리터러시 (그룹별 트랙)
- 직무·숙련도 진단 기반 커리큘럼 설계

### ② 프로젝트형 교육 — **3~4주**
각 구성원이 *본인의 실제 업무*에 AI를 적용해 결과물(산출물)을 뽑고, 그 과정에 1:1 디테일 코칭이 붙는다.

실제 기업이 많이 필요로 하는 예시:

- 재무팀 — 월말 결산 데이터 대사·검증 자동화
- CS팀 — VOC 자동 분류·태깅 파이프라인
- 영업팀 — 사내 템플릿 기반 제안서·견적서 초안 생성기
- 마케팅 — 캠페인 카피 변형 + 성과 리포트 자동화
- HR — 채용공고·JD 표준화 + 지원자 요약

### ③ 기업 맞춤 AX 엔지니어링
기존 툴로 안 되는 지점은, 사내 환경·보안에 맞는 AI 자산을 만들어 배포·운영한다 (FDE 방식).

- 사내 문서·드라이브 검색 **MCP 서버**
- 부서별 프롬프트 **템플릿 라이브러리**
- 반복 업무용 **skills 패키지** (회의록→액션아이템, 주간 리포트 생성 등)
- 그룹웨어·ERP·Slack **커넥터/플러그인**
- 보안 검토 + 사내 챔피언 육성으로 배포·운영 정착

> 참고: 기존 `content.ts`의 5단계 프로세스/FDE 섹션은 이 3축을 더 선명하게 반영하도록
> 후속 작업에서 정렬한다. 산업 카드·후기의 "10주" 표현은 3~4주 기준으로 재검토 대상.

## 3. 브랜드 비주얼 톤

- **라이트 테마** (다크 아님): `--bg:#f5f5f5`, 흰 패널, 검은 텍스트.
- **오렌지 메인** `--brand:#ff7a33` + 파스텔 포인트 6색 (peach/amber/rose/lilac/sky/mint).
- 모션은 은은하고 절제된 결. 텍스트 가독성 최우선.

## 4. Hero 배경 영상 컨셉 (컨셉 ① 리테마)

추상 입자가 아니라 **유쳐 스토리 그 자체**를 모션으로:

> 흩어진 **개별 구성원 노드**(각자 수작업, 무채색) → 유쳐가 들어가며
> **3갈래 흐름**(교육 · 코칭 · 엔지니어링)이 관통 → 노드들이 오렌지로 점등·연결되며
> **돌아가는 에이전트/도구가 있는 정돈된 조직 그리드**로 재편된다.

= "AI를 아는 조직에서 AI로 일하는 조직으로"의 시각화.

### 레이아웃·기술 제약
- 라이트 바탕. 왼쪽 카피 영역(텍스트)은 비우고 오른쪽~중앙에서 흐름.
- 저투명도 풀블리드, 텍스트 대비 유지.
- 색: 오렌지 메인 + 파스텔 포인트. 무채색 → 오렌지 점등 전이.
- 제작: `motion/` Remotion → 라이트 WebM 루프 → `web/public/assets/motion/`로 출력
  → `MotionGraphic`/`<video>`로 Hero 배경 임베드. (spot-search.webm과 동일 파이프라인)
- 루프 길이 목표: 8~12초 심리스 루프.

### 모션 비트 (초안)
1. (0~2s) 흩어진 무채색 노드 필드 — 각자 고립.
2. (2~5s) 좌측에서 3갈래 흐름이 들어와 노드를 통과 → 노드 점등(오렌지).
3. (5~8s) 점등 노드들이 연결선으로 묶이며 정돈된 그리드로 재배열, 작은 도구/에이전트 타일이 가동.
4. 심리스 루프백.

## 4.5 산업별 AX 전환 맵 (핀드 인터랙티브 섹션)

3blue1brown 식으로 "구조가 눈으로 읽히는" 모션. 어느 분야든 AX로 전환된다는 걸,
흩어진 수작업이 파이프라인으로 재조립되는 과정으로 보여준다.

- **자리:** `FdePipeline` 다음, `IndustryCards`(실제 사례 통계) 앞에 새 섹션. Hero 배경은 유지.
- **방식:** in-page SVG + GSAP ScrollTrigger 핀드 스크롤(scrub). 영상 아님 — 진짜
  인터랙티브(스크롤이 산업을 훑음), 라이트 테마 토큰, 벡터 라벨로 선명. progress(0..1)에서
  imperative 계산 → ref 직접 갱신(리렌더 없는 부드러운 scrub). `prefers-reduced-motion`이면
  정적 리스트 폴백.
- **모션:** 흩어진 회색 수작업 노드 클라우드 → 검색·생성·자동화 3단계 파이프라인으로 변형.
  스크롤로 6개 분야를 하나씩 재생(각 분야마다 scatter→assemble→hold→release) → 마지막에
  전 분야 동시 점등 "모든 분야로 번집니다".
- **데이터:** `content.ts > axMap` (분야 / kind(검색·생성·자동화) / before(수작업) / after(AX 결과)
  / stages 3단계). 실제 기업 니즈 기반 6개: CS(VOC 분류·자동화), 전사(문서 검색), 영업(견적
  생성), 재무(정산 검증·자동화), 마케팅(리포트 생성), 인사(채용 검색).
- **구현:** `web/src/components/AxTransformMap.tsx`, 스타일 `.axmap-*` in `components.css`.
