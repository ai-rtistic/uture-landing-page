## 🔴 P1 — 기업 담당자 전환에 직결 (먼저)

- [ ] **1. 문의 전환 경로 업그레이드 — mailto 탈피**
  현재 모든 CTA가 `mailto:` (메일 앱 팝업 = B2B 최악의 마찰, 회사 PC에서 메일 클라이언트 미설정이면 아무 일도 안 일어남).
  FinalCTA(#contact)에 **인라인 문의 폼**(회사명 · 담당자 · 연락처 · 고민 한 줄) 또는 캘린더 예약 위젯.
  백엔드 없으면 Formspree/Tally 임베드 또는 폼 → mailto 조합이라도. *가장 임팩트 큰 항목.*

- [ ] **2. OG/소셜 메타 + 공유 카드** — `index.html`에 og:title/og:description/**og:image**/twitter 카드 없음.
  담당자가 사내 메신저에 링크 공유하는 순간이 첫인상 — 브랜드 og 이미지 1장 제작 포함.

- [ ] **3. 사례 "더 알아보기" 링크가 #contact로 감** (`IndustryCards.tsx:31`)
  "더 알아보기"를 눌렀는데 문의 섹션으로 떨어지면 낚임 느낌 → 신뢰 하락.
  ① 카드 인라인 확장(과제→개입→결과 3줄 케이스 요약)으로 바꾸거나 ② 문구를 "도입 문의 →"로 정직하게.

- [ ] **4. 법적 링크 살리기** — 푸터 이용약관/개인정보처리방침 `href="#"` (content.ts legal).
  개인정보처리방침 없는 B2B 사이트는 기업 검토 단계에서 감점. 정적 페이지 2개 생성 + 연결.

- [ ] **5. 탭 데모 높이 점프** — 세 데모 스테이지 높이 528/370/327px로 제각각 → 탭 전환 때 섹션이 출렁.
  `.services-demo`에 고정 min-height(≈530) 또는 세 데모 콘텐츠 밀도 통일.
